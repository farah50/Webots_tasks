<h1>Maze Solving with A* Algorithm</h1>
This project demonstrates the implementation of an A* searching algorithm to solve a maze using an e-puck robot. The robot is equipped with distance sensors to navigate through the maze.

![Screenshot 2024-07-14 002831](https://github.com/user-attachments/assets/e608d0bd-5288-4b6c-b11f-747cb95174ff)

<h2>Features</h2>
<ul>
  <li>A* Searching Algorithm: Efficiently finds the shortest path from the start to the goal within the maze.</li>
  <li>Distance Sensors: Used to detect obstacles and ensure the robot follows the correct path.</li>
  <li>Visualization: Real-time visualization of the maze, the robot's path, and explored nodes using matplotlib.</li>
  <li>Moving the quantifier to the left</li>
 
</ul>
