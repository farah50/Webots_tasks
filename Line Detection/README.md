<h1>E-Puck Robot Line Following</h1>

This project involves an e-puck robot equipped with distance sensors used to detect a line on the floor 

![img (2)](https://github.com/user-attachments/assets/db6f9c71-e26d-4d83-a9b9-e4a6b5e7f5aa)


<h3> Note </h3>
To make the line appear, download tinker.obj file and then go to Transform --> children --> shape --> geometry Mesh --> url and click on select button to upload the file on the world
