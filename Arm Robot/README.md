# Arm Robot Simulation  

This project demonstrates a robotic arm simulation built in Webots, where the arm is tasked with detecting, picking up, and placing bottles into crates.  

The project applies **Forward Kinematics (FK)** and **Inverse Kinematics (IK)** concepts:  
- **Forward Kinematics (FK):** Calculating the position and orientation of the robot’s end-effector from given joint parameters.  
- **Inverse Kinematics (IK):** Determining the required joint angles to reach a specific target position for object manipulation.  

This makes the project not only a practical simulation but also a direct application of fundamental robotics and kinematics principles.
