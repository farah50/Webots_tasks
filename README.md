# Projects Overview
This repository contains implementations of various robotics projects using Python and the Webots simulation environment. 

<h2>1. Obstacle Avoidance with Distance Sensors</h2>
This project features a robot with distance sensors that enable it to navigate an environment while avoiding obstacles.

<h2>2. Line Following with Infrared Sensors</h2>
In this project, an e-puck robot with infrared (IR) sensors is designed to follow a line marked on the floor. The robot adjusts its trajectory based on IR sensor readings to stay aligned with the line, demonstrating precise control and path-following capabilities.

![img (2)](https://github.com/user-attachments/assets/38325a5f-c582-4007-9d73-3b8b29411cd5)

<h2>3. Maze Solving using A* Search Algorithm</h2>
This project implements the A* searching algorithm for maze solving by a robot. The robot navigates through a maze environment from a starting point to a goal while avoiding obstacles. The algorithm computes the shortest path using heuristic functions and updates the robot's movement accordingly.

<h2>Features</h2>
<ul>
  <li>A Search Algorithm*: Finds the shortest path through the maze.</li>
  <li>Heuristic Functions: Used to estimate the distance from the current position to the goal.</li>
  <li>Visualization: Real-time visualization of pathfinding and explored nodes.</li>
</ul>
